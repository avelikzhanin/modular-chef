# ТЗ — Modular Chef (мил-преп приложение)

> Единый источник правды по продукту и дизайну. Собрано из всех обсуждений.
> Стек: Flutter (моб.) + FastAPI + PostgreSQL + OpenAI на Railway.

---

## 1. О продукте
Приложение модульного питания (meal-prep) с двумя ролями:
- **Шеф** — планирует и готовит впрок (на 2 недели), задаёт заготовки.
- **Гость** — ест «сегодня», собирает тарелку из того, что Шеф заготовил.

Концепт: лёгкий модульный выбор ингредиентов → AI собирает 14-дневное меню «тарелок» (белок + гарнир + овощ + соус) → список покупок → день заготовки → запасы, из которых Гость собирает приёмы пищи.

## 2. Дизайн-система «Лён, песок и молодой лист»
> Эволюция «Лён и глины»: тёплые воздушные нейтралы + свежий зелёный «молодого листа» как акцент (вместо коралловой глины) + **акварельная графика**. Эмоция: нежно, природно, «располагающе, хочется готовить» — современная кулинарная книга.

Тень — тёплая, низкая: `0 8px 24px rgba(46,38,32,0.06)` (никогда не чёрная).

### 2.2 Типографика (редакторская «книжная»)
- Заголовки/display — **Fraunces** (мягкий сериф), **вес 600**, плотный трекинг (-0.02em). Размеры: display 48 / headline 32·28·24 / title 20.
- Текст/UI — **Inter** (body 16–18, w400).
- **Подписи/метаданные** (надписи!) — Inter, label-sm **12/600 в разрядку +0.05em, часто КАПСОМ**: «СВЕЖЕСТЬ 85%», «2 порции», «ШЕФ РЕКОМЕНДУЕТ», «ОСТАЛОСЬ 2 ДНЯ».
- (В Stitch сериф = Noto Serif как замена Fraunces — у нас Fraunces.)

### 2.3 Формы и компоненты
- Карточки: Cloud Paper, радиус **24px**, тёплая мягкая тень; опц. «двойной бортик» (внешняя оболочка + внутреннее ядро).
- Кнопки: **зелёный `#8FB96A`**, текст `#23351A`, радиус **14px** (мягкий прямоугольник, не пилюля). Вторичная — ghost/outline оливой.
- Чипы: маленькие пилюли, активный = Light Leaf + Leaf Deep.
- Выделение: мягкая заливка Light Leaf + 1.5px зелёный контур + лёгкий scale при тапе.
- Фактура: деликатное «зерно» бумаги (~3%) по всему приложению.

### 2.4 Графика — акварель (watercolor)
- **Фон-подложка:** рисованное акварельное небо с мягкими облаками (персик/блаш/крем), плавно тает в лён. Файл `assets/art/bg_clouds.png`.
- **Иконки продуктов:** hand-painted **watercolor wash** — мягкие размытые края, фактура бумаги, без жёстких контуров; палитра молодой лист/олива/терракота/персик/крем. НЕ эмодзи, НЕ детские.
- **UI-иконки** (навигация, действия): тонкая акварельная линия в **одном цвете — глубокий зелёный лист `#436823`** (не серый монохром, не разноцветные). Активная вкладка выделяется светло-зелёной плашкой Light Leaf `#DCE9C8` под иконкой, а не сменой цвета. Еда остаётся разноцветной акварелью — баланс «яркая еда / спокойный одноцветный хром».

### 2.5 Анимация
Пружинные появления, каскадный fade-up списков, мягкие микровзаимодействия (transform/opacity).

### 2.6 Анти-паттерны
Без эмодзи в UI; без чистого чёрного; без неона/глоу/фиолетово-синих AI-градиентов; без жёстких серых рамок; без 3 одинаковых карточек в ряд; без кислотной «детской» пастели. Насыщенная **природная** пастель — приветствуется.

## 4. Голос и копирайтинг
Тон — тёплый, редакторский, сенсорный, на «ты», как кулинарная книга. Слоган: **«Искусство готовить заранее»**.

### 4.1 Заголовки/подзаголовки экранов (внедрено)
- Собери меню: «Искусство готовить заранее — выбери, что любишь, остальное соберём.»
- Сегодня: «Собери день из того, что Шеф приготовил заранее.»
- Запасы: «Свежесть заготовок под контролем — ешь, пока они в лучшей форме.»
- Профиль: «Твоя кухня и твои привычки — всё, что делает меню „твоим“.»
- Список покупок: «Всё для недели в одном списке — отметь, что уже есть дома.»
- Подготовка: «Выбери способ и загляни в детали — как готовить и где хранить.»

### 4.2 Бейджи блюд (план)
«Шеф рекомендует» · «Пряное» · «Высокий белок» · «Лёгкое» · «Веган» · «Быстро» · «Сытно».

### 4.3 Свежесть/хранение (план)
«СВЕЖЕСТЬ 85%» · «Осталось 2 дня» · «Употребить завтра» · «Съесть сегодня» · «(2 порции)».

### 4.4 Пустые состояния (план)
- Ужин не собран: «Ужин ещё не собран — загляни в запасы и собери за минуту.»
- Банки пусты: «Тут пока пусто — собери первую банку, и Гостю будет что взять.»
- Меню не собрано: «Меню ещё не собрано — выбери ингредиенты и нажми „Собрать меню“.»
- Любимые пусты: «Любимых сочетаний пока нет — отметь ♥ на тарелке.»

### 4.5 Подсказки сборки (внедрено)
- Тарелка: «✓ Проверенное сочетание (русская кухня)» / «💡 Необычно — к стейку чаще берут картофель».
- Баночка: «Гранолу добавь утром, иначе размокнет» · «Кислый фрукт на молочной основе — съешь сегодня» · «Банан темнеет — под прокладку или утром».

### 4.6 Банк фраз «Запасы» / карточки блюд (из дизайна Stitch)
- Подзаголовок-герой: «Свежесть приготовленных модулей под контролем. Наслаждайтесь вкусом, пока продукты в лучшей форме.»
- Карточка блюда: название с порциями «… (2 порции)» + бейдж + описание (1 строка) + бар свежести.
- Бейджи: «Шеф рекомендует» · «Пряное» · «Высокий белок».
- Описания (тон): «Бархатистая текстура с нотками мускатного ореха. Идеально сочетается с сухариками из ржаного хлеба.» · «Нежное филе в кокосовом соусе с куркумой и имбирём. Готово к разогреву.»
- Бар свежести: «СВЕЖЕСТЬ 85% · Осталось 2 дня»; при истечении — красным «Употребить до завтра».
- Сводка «Обзор запасов»: «Готово 5 порций еды на ближайшие дни» + чипы «2 супа», «3 основных блюда».
- Алерт пополнения: «Время пополнить запасы? Через 2 дня холодильник опустеет. Посмотрите новые модули от шефа, чтобы спланировать следующую неделю.» → CTA «Собрать новое меню».

## 5. Функционал

### 5.1 Завтрак-конструктор (внедрено)
- **Яйца:** 6 видов (омлет/скрэмбл/глазунья/шакшука/пашот/варёные); добавки фильтруются по виду (готовка vs подача).
- **Баночка:** 4 слоя (основа/прокладка/сочный/хруст) по ~15 вариантов + правила-подсказки совместимости слоёв.
- Простые типы: сырники/каша/бутерброд/гранола.

### 5.2 Гость (внедрено)
- **Сегодня** — 4 слота (завтрак/обед/ужин/перекус): собрать / пропустить / очистить.
- **Сборка** — из заготовок Шефа: готовые банки берёт целиком, яйца — из выбранных Шефом видов; если Шеф не заготовил — фолбэк на каталог. Подсказки сочетаний на main-тарелке.
- **Запасы** — что есть, по категориям.

### 5.3 Шеф (внедрено)
- **Собери меню** — лёгкий выбор; соусы подбираются авто (плашка). Расширенный набор соусов/заправок (23).
- **Меню на 2 недели** — полные тарелки; **точечная замена «тап по продукту → выбери, в каких блюдах → замени»** (+ «выбрать все»).
- **Заготовки завтраков** — Шеф собирает конкретные банки (конструктор слоёв) и выбирает виды яиц/добавки → из этого собирает Гость.
- **Подготовка** — способы + хранение по белкам/гарнирам/овощам/супам.
- **Список покупок** — «Купить» / «Уже есть».
- **Профиль** — Мои блюда, Мои сочетания, Заготовки завтраков, Предпочтения.

### 5.4 Подсказки сочетаний
Матрица `pairings.json` (тройки белок+гарнир+соус с тегами кухни). На сборке/правке — мягкие подсказки, не блокируют.

## 6. Бэкенд / генерация
- Меню собирает LLM (gpt-4o, JSON-mode) по промпту `assets/prompts/menu_generator.md`.
- **Компактный контракт:** LLM возвращает только `kind` + `modules` (id) на приём — бэкенд достраивает роли/имена/эмодзи/заголовки/контейнеры/статистику из каталога. Экономия токенов в 3-4×, нет обрезки, ~10-15 сек.
- Каталог — в БД (`modules`), сидится из `assets/data/modules.json` на старте контейнера.
- **Деплой:** GitHub-автодеплой Railway не срабатывает → деплоим `railway up --detach --service modular-chef` из `D:\Desktop\modular_chef`.
- **Нюанс DNS:** на некоторых сетях телефона railway.app не резолвится (Failed host lookup) → сменить сеть / Приватный DNS `dns.google` / VPN.

2. **Зелёная кнопка в приложении** — сейчас в коде акцент ещё глина `#AE6A4D`; переключить тему на молодой лист `#8FB96A` (+ опц. глубокий зелёный `#436823` для активной навигации).
3. **Глубокая микрокопия** — бейджи блюд, свежесть/хранение, пустые состояния (тексты в §4.2–4.4).
4. **Картинки еды** (top-down акварель) на карточки — при ассетах.
5. Ротация утёкших ключей (OpenAI/Postgres) — безопасность.
